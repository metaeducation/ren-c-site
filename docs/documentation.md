# Documentation

Everything under `/docs/` is reference material.  The examples on these
pages are run by a current Revolt interpreter every time the site is built,
so they show what the interpreter actually does.

* [Concepts](/docs/concepts/) -- the ideas that cut across the language
* [Datatypes](/docs/datatypes/) -- every type of value
* [Natives](/docs/natives/) -- the functions built into the interpreter
* [Dialects](/docs/dialects/) -- little languages, like PARSE
