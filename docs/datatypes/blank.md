The comma.  In code it separates expressions, making boundaries clear while producing nothing itself:

    reduce [1 + 2, 3 + 4]

In a list it shows as a comma, so `[a, b]` has three elements.

Its antiform is [VOID!](/docs/datatypes/void/), and its quasiform is the bare tilde `~`.
