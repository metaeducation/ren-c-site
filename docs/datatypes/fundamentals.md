# Fundamental Types

The types a value in a list can have.  Each has a page; the
[Datatypes](/docs/datatypes/) index groups them by kind.

The containers are fundamental too, but have sections of their own, since
each family shares a lot: [List Types](/docs/datatypes/lists/) (BLOCK!,
GROUP!, FENCE!) and [Sequence Types](/docs/datatypes/sequences/) (TUPLE!,
CHAIN!, PATH!).

Several were renamed from historical Rebol: TEXT! was STRING!, BLOB! was
BINARY!, GROUP! was PAREN!, and RUNE! replaces CHAR! and ISSUE!.  FENCE!
and CHAIN! are new, and TUPLE! is now a general sequence.
